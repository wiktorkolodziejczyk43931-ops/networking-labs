# Two-Site Cisco Enterprise Lab

Physical cabling design for an isolated Cisco lab that models a head office and a branch office. The head-office Cisco 1941 and branch Cisco 1921 have a direct Ethernet WAN link. Each site uses a Catalyst 3560-48PS switch, and the Viglen host sits at head office.
